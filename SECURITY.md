# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a Vulnerability

Open a private security advisory on the hosting GitHub repository, or email the repository maintainers. Include reproduction steps without attaching identifiable ICSR records.

## Data Handling

- Treat ICSR workbooks as confidential.
- Do not commit production datasets.
- Do not publish patient narratives, names, or contact details in issues, logs, or sample files.
- Generated reports remain drafts until a qualified reviewer approves them. They are not autonomous regulatory decisions.
